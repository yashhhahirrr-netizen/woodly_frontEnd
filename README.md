# Woodly Frontend Application

Enterprise-level React 18/19 + Vite + Tailwind CSS + MUI + Redux Toolkit + Framer Motion + Recharts frontend for **Woodly Enterprise Furniture Marketplace**.

## Features
- **Modern Dark Gold Theme**: 60% Dark (`#121212`), 30% Gold Accent (`#FFC107`), 10% White highlight aesthetic with glassmorphism overlays and custom scrollbars.
- **Multi-Role Portals**:
  - **Customer Portal**: Animated Hero Banner, Mega Menu Navbar, Multi-faceted Filter Sidebar (price, category, brand, material, color, rating), Interactive Product Detail with 360° Rotator & Hover Image Zoom, Wishlist, Cart Drawer & Cart Page, Multi-Address & Gateway Switcher Checkout, Order Tracking Timeline with status updates.
  - **Supplier Portal**: Shop Dashboard with weekly sales graph (Recharts), Inventory Data Table with Add/Edit Furniture Modal, Low Stock warnings, Order processing queue.
  - **Super Admin Portal**: Enterprise Analytics Dashboard with Revenue Area Chart & Category Distribution Pie Chart, Supplier Shop Moderation Queue, Platform User Management with block/unblock controls, Audit Trail viewer.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Build for Production
```bash
npm run build
```
